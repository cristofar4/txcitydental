# Hero video

Drop a short, muted, looping practice walkthrough here named **`hero.mp4`**
(an MP4, ideally 1080p, 10 to 20 seconds, a few MB). The homepage hero will
play it automatically.

Until a file is present, the hero shows a cinematic, slowly panning photo, so
it always looks like motion footage. You can change the path in
`src/lib/site.ts` (the `heroVideo` field) to point at any hosted .mp4 instead.
